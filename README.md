# Jogo Dominó

Jogo de dominó feito em C++ durante o segundo semestre da faculdade. No nosso jogo de dominó, permitimos que o jogador jogue contra um amigo, contra o computador e também que possa salvar ou carregar um jogo previamente salvo.
